# debug/ — 调试与修改记录

本目录记录 ResearchClawEval 公开仓库在真实评测中排障、修复的完整过程,面向团队协作与后续整合。

## 目录结构约定

- **顶层**：仓库级问题——线束/适配层 bug、发布脱敏遗漏、上游框架行为缺陷等,**对所有协作者的环境都成立**。
- **`<协作者名>/` 子目录**（如 `dawei/`）：该协作者**环境特有**的问题与处置（机器、网络、镜像批次、路径布局等）,供他人参考但不代表仓库缺陷。其他协作者遇到环境问题时,请建立自己的同名子目录。

| 文件 | 层级 | 内容 |
|---|---|---|
| [2026-08-26-01-arc-bug-analysis.md](2026-08-26-01-arc-bug-analysis.md) | 仓库级 | 框架 01 × ARC "跑不出分数" 的完整 bug 链分析与可复现证据 |

## 记录约定

- 每条记录写清：现象 → 证据（日志/路径/复现命令） → 根因 → 处置（含 commit 号） → 影响面。
- 修改一律标注作用域（哪些文件、影响哪些 framework×topic 组合）。
- 判断层级的标准：**换一台机器/换一个人还会复现吗？** 会 → 仓库级;不会 → 环境级。
- 失败 run 的目录按 AGENTS.md 规定全部保留,文中引用 run id 即可回溯。
